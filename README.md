# Practicing-html-on-my-own
I started learning HTML through [freeCodeCamp](https://www.freecodecamp.org/), where I practice and share the exercises and projects I complete as part of their curriculum.

After learning the basics, I wanted to go beyond the guided exercises and start experimenting with HTML on my own — trying out different ideas, building small things from scratch, and practicing what I've learned without following a specific tutorial or challenge.

I already have another repository dedicated to my freeCodeCamp exercises and projects. I created this repository to keep track of the things I build and experiment with independently as I continue learning and improving my HTML skills.

This is basically my space to **learn, experiment, make mistakes, and build things on my own.** 🚀
